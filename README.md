# FindBack Backend

REST API for the **FindBack — Lost & Found** MERN application.

**Stack:** Node.js, Express, MongoDB, Mongoose, JWT, Zod.

## Quick Start

1. Copy `.env.example` to `.env` and set your `JWT_SECRET` and `MONGODB_URI`.
2. Run:

```bash
npm install
npm run seed
npm run dev
```

API runs on `http://localhost:5000/api`.
